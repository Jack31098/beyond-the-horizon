# Beyond the Horizon｜节目资料库

这是 YouTube 节目制作项目。核心形式是人类主持人与 AI 对话：从具体经历、技术问题或社会观察出发，通过追问、反驳和修正形成节目。原始聊天记录是素材，不是可以直接照读的定稿。

## 从这里接续

1. 读 [HANDOFF.md](HANDOFF.md)：当前进度、尚未持久化的部分和下一步。
2. 读 [sources/conversations.md](sources/conversations.md)：原始对话索引与增补链接。
3. 按选题读 `notes/` 中的卡片。卡片区分原始对话观点、已独立核实的事实和待核实的推断。

工作时先更新资料卡，再形成节目提纲；每次结束前更新 `HANDOFF.md` 的游标和核实状态。不要把旧 AI 的赞同当成独立证据，也不要把多年合同规模直接算作某一年已确认收入。

Git 保存的是这些可审阅的文字结果。跨机器继续工作还需要把本仓库推送到你控制的远端，再在另一台机器克隆；仅有本地仓库或 OneDrive 同步不能替代 Git 远端。
